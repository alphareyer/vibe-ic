# F4 source contract and integration handoff

F4 owns `execution_adapters_release.py`, `execution_release_worker.py`,
`execution_release_rows.py` and its source controls. F1 owns the readonly
`execution_step_protocol.py` dependency, registrar, lease issuer and all runner
hooks. Register `execution_adapters_release` explicitly with FactoryRegistry.

`prepare(StepRequest)` consumes actual `top`, `pdk`, `route` (IC/IP), `image`,
`declaration` (canonical Path) and `input_roots` (name to absolute upstream Path).
Roots must include the current owner-cited declaration and every actual consumed
design/report/model file. Missing roots and lexical aliases remain bound. Roots
exclude unrelated mutable downstream outputs; this module additionally excludes
the current row's actual producer/report destinations. F1 supplies an absolute
lease directory containing its original `lease.json`, plus an independent record
directory. These bytes are frozen controls, never domain-issued native authority.

F1 calls `required_source_files(parameters)` before issuing the common source
manifest. That inventory includes production Python modules, this worker/factory,
canonical flow/routing/portfolio data, Python and read-only Git binaries, and
separately declared native binaries. Add other families' actual dependencies in
F1, then supply that complete common map unchanged. No domain extends a request's
manifest. Every arm uses exactly the issued map.

`semantic_consume(project, context, controller, run, adopted)` imports only the
live controller's exact selected population. It evaluates actual original
consumers before import and again on bytes read back from installed canonical
paths. Secondary checker writes stay in private snapshots. Import refusal rolls
back old and new canonical writes. PreparedStep.adoption_paths contains concrete
files/directories, covering every product and complementary report. The result
contains IMPORTED, step/source/issued generation/current binding, actual copied
hashes, actual primary gates, code qualification, design verdict and nested
CONSUMED consumer detail. Source qualification never erases a measured FAIL.
