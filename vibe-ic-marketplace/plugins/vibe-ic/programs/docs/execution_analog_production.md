F5 exports `execution_adapters_analog.STEP_IDS` (A1–A9/M1–M4) and
`prepare(StepRequest) -> PreparedStep`. F1 alone registers the factory and
writes runner hooks. Its staged immutable f199 shared API is a read-only dependency,
not part of this family's functional patch.

The verified worker scopes `VIBEIC_EXECUTION_NATIVE_STEP` to its exact current
binding while calling the existing producers and per-block semantic consumer,
then restores the previous environment even on refusal. This uses F1's existing
same-step reentry guard for software as well as native children. It does not
register the domain, bypass another step, issue adoption or admit native work.
Actual default installation still requires F1's next immutable registrar and
typed callable hooks; an explicitly populated private registry is insufficient.

The front door supplies current absolute Path `project`, Path `declaration`
(the actual Phase-1 analog block list), a lease directory with `lease.json`,
and an unused outside-project request-record Path. Parameters have an explicit
serializable schema through F1 `json_parameters()`: JSON scalars/containers,
Path values, dataclass fields and argparse Namespace values. Unsupported
objects and nonfinite numbers are refused. Every arm
and context uses the complete `request.source_files` unchanged. F1 must include
`source_dependencies()` plus host Python and each actually used binary. Source
hash equality is checked at preparation, execution and adoption boundaries.

Parameters common to each step are `input_roots` (F1 mapping of lexical names
to absolute consumed Paths), `objective`, `cpus`, `ram_mb`, `timeout_s` and
`declaration`. The earlier project-relative list remains a source-control API.
All consumed lexical names, aliases, missing roots and file digests are frozen;
current-step output qualification patterns are excluded separately. Upstream
reports are INPUT, including their real native provenance. A missing input or
model never creates a successful empty check. `adoption_paths` contains actual
canonical files/directories, while qualification patterns remain internal.
For a native block sharing a directory with upstream spec/topology/layout,
the request must supply exact `adoption_paths` for the actual producer files
and dedicated output directories. A broad wildcard-parent journal that
contains consumed INPUT is refused; INPUT is never dropped to permit it.
Imported products must fit both the owned output contract and that concrete
journal. Additional native producer views/child files must be declared before
the request and verified on the actual INPUT; they remain unqualified here.

Native parameters include the actual `pdk_name`, `pdk_root`, `image_id`, parsed
`native_facts` dict, matching `native_facts_file` Path, actual F1-issued lease
and `native_deadline_s` from real capacity admission. The parsed facts must
equal the file bytes' JSON. The image must be immutable. A source reservation
does not authorize native work. Missing native facts/admission/dependency keeps
an applicable software producer unavailable or unqualified, never a fabricated
physical declaration. F1/P0 owns `execution_resource_lease.native_boundary`
and the existing `librelane_contract.run_container` skip-first Docker run.
There is no Docker exec, entrypoint override or own global tiny memory budget.
The domain local backend runs intact legacy tool commands inside that one
ephemeral container and serializes its native calls. Raw native rc/PID/logs
and outer run commands remain bound outputs.
At `_native_launch`, F1 `record_worker(lease, readonly_mounts=...)` records
the actual Controller-launched session/group leader and frozen input mounts.
The domain never writes the shared last-worker alias itself or fabricates
process identity. Registration refusals propagate before the native boundary;
invocation-bound mount selection and lifecycle recovery remain F1-owned.

Only interchangeable independently measured engines may compete. The currently
implemented native producer is one ordered complementary chain per step;
wrappers sharing engines do not create extra ultra-mode candidates. Unqualified
Xyce/ALIGN/licensed alternatives are not advertised as measured competitors.

`consume(project, context, controller, run, adopted)` re-enters the live
controller issuer, checks the exact selected generation and INPUT/source/output
bindings, journals every canonical write, imports issued bytes, reruns existing
semantic consumers on a view of those exact bytes and rolls back on refusal.
It uses F1 `imported_result()` to return `IMPORTED`, step/source/full issued
`selected_generation`/binding, nonempty `copied` hashes,
actual `primary_gates`, preserved `design_verdict` and nested consumer detail.
A measured FAIL never becomes NOT_MEASURED merely because no artifact is eligible.
An actual mandatory consumer `FAIL` is retained in the raw refusal detail and
propagates `GATE_FAIL` after rollback; missing/unbound/unexecuted consumers retain
their original refusal classes. F1's journal then records `ROLLED_BACK`/`FAIL`.
The source frontdoor example uses the actual F1 lease issuer and `_consume`
journal and typed verifier. This software fixture does not admit native jobs,
qualify an independent AI selection or replace missing current owner INPUT.
Native `ram_mb` is the total F1 lease budget; `container_ram_mb` is the actual
smaller OCI quota after the host allowance. Recovery records include worker
PID and actual start ticks. Native transport/validators remain unqualified;
in particular A7 needs its existing nested LibreLane seam, and A6/A8 consumer
native branches need the same admitted transport before a capacity example.

The finite source controls execute the real A1 primary and established semantic
consumer, plus stale/added/deleted/alias/source/generation/output/gate failure
controls. Synthetic M2/SI data exercises derivation only; it is not native
qualification. Current F1 front-door integration, actual owner A1 input and
INPUT-bound native examples remain separate capacity/integration obligations.
No original source/policy/assertion is deleted or weakened. The complete original
75 HARVEST items and 13 canonical rows are retained in
`data/execution_analog_contracts.json`; new stricter consumers preserve their
existing source destinations pending the original FIRST correctness/integrity pair.
